# Personal Expense Tracker

A CLI-based Personal Expense Tracker built using Python, Object-Oriented Programming (OOP), File Handling, and JSON.

## Features

- Add expenses
- View all expenses
- Track expense categories
- Store data using JSON files
- Simple command-line interface

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON File Handling

## How to Run

1. Clone the repository

2. Open the project folder

3. Run:

python main.py
